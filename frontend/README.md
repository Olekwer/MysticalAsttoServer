# Mystical Astro Frontend

Тестовый фронтенд для API астрологического сервиса

## Технологии

- **Vite** - быстрый сборщик проектов
- **React 18** - библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript
- **Zustand** - легковесное управление состоянием
- **Tailwind CSS** - utility-first CSS фреймворк
- **Axios** - HTTP клиент для API запросов

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Настройте переменные окружения:
```bash
cp env.example .env
```

Отредактируйте `.env` файл:
```env
VITE_API_URL=http://localhost:3010
VITE_APP_NAME=Mystical Astro
```

3. Запустите сервер разработки:
```bash
npm run dev
```

4. Откройте браузер по адресу: `http://localhost:5173`

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `VITE_API_URL` | URL API сервера | `http://localhost:3010` |
| `VITE_APP_NAME` | Название приложения | `Mystical Astro` |

## Функциональность

### Аутентификация
- Вход с email/password
- Вход с magic link
- Сохранение состояния в localStorage
- Автоматическое добавление токенов к запросам

### Астрологические функции
- Генерация натальной карты
- Ввод данных о рождении (дата, время, место)
- Отображение основных астрологических данных

```
└── index.css           # Глобальные стили
```

## API Endpoints

Фронтенд настроен для работы с API по адресу из переменной `VITE_API_URL`:

- `POST /auth/login` - вход с паролем
- `POST /auth/magic-link` - запрос magic link
- `POST /astro/natal-chart` - генерация натальной карты
- `GET /astro/transits` - получение транзитов
- `POST /astro/synastry` - синастрия
- `GET /health` - проверка здоровья API

## Разработка

Для добавления новых функций:
1. Создайте компонент в папке `components/`
2. Добавьте store в папку `stores/` если нужно
3. Обновите `App.tsx` для интеграции
4. Добавьте стили в `index.css` при необходимости
5. Используйте `apiService` для HTTP запросов
